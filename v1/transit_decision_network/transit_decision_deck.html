Rules and safeguards

Eligibility is not the same as approval.

PyRel rules screen route-bus-driver combinations. Plan-level constraints then determine whether a set of eligible options is dispatchable.

Resource availability

Vehicle and driver must both be available.

Shift time

Route duration cannot exceed the driver's remaining shift.

Accessible route qualification

An accessible route needs an accessible bus and qualified driver.

Plan-level South safeguard

Selected assignments must provide at least 30 accessible rider places in the South.

Prescriptive reasoning

Optimization chooses the portfolio, not a ranked list.

A binary choice for each eligible assignment, plus an explicit unmet-demand variable for each zone.

problem.solve_for(
    Option.selected,
    where=[Option.eligible()],
    name=["route_id", "vehicle_id", "driver_id"],
    type="bin",
)

problem.satisfy(model.require(
    aggs.sum(Option.selected * Option.cost)
    <= budget_usd
))

problem.minimize(
    aggs.sum(Option.selected * Option.cost)
    + penalty_per_unmet_rider_usd
      * aggs.sum(Zone.unmet)
)
problem.solve("highs", time_limit_sec=60)
Hard limit

Operating cost stays at or below $18,000.

Scarce resources

One assignment per vehicle, driver, route, and zone.

Service floors

Minimum capacity in every zone and 30 accessible places in the South.

Soft shortfall

Each unmet rider adds $250 to the objective. Shortfall is reported, never hidden.

Querying decision outcomes

Whose approved decisions had the highest estimated return?

The ontology joins actor → review → run → outcome. Counterfactuals and unapproved proposals do not receive ROI credit.

model.where(
    Action.actor == Actor,
    Action.run == Run,
    Outcome.run == Run,
    Action.action == "approved",
    Run.kind == "policy_constrained",
    Outcome.evidence_kind == "synthetic_follow_up",
).select(
    Actor.name.alias("actor"),
    (aggs.sum(Outcome.estimated_net_value_usd).per(Actor)
     / aggs.sum(Outcome.simulated_incremental_spend_usd)
         .per(Actor)).alias("estimated_roi"),
)
