# v0.14 Templates

This directory contains the templates for v0.14. Each template folder includes its own code, data, and detailed README.

## Template Index

| Template | Description |
| --- | --- |
| [ad_spend_allocation](./ad_spend_allocation/) | Allocate a fixed budget across channel–campaign combinations to maximize expected conversions, subject to channel spend bounds and per-campaign budget limits. |
| [diet](./diet/) | Select foods to satisfy daily nutritional requirements at minimum cost. |
| [factory_production](./factory_production/) | Choose production quantities per machine-product pair to maximize profit while meeting minimum production requirements. |
| [grid_interconnection](./grid_interconnection/) | Approve data center interconnection requests and substation upgrades to maximize net revenue within capital budget. |
| [hospital_staffing](./hospital_staffing/) | Assign nurses to shifts to minimize overtime cost and overflow penalties from unmet patient demand. |
| [inventory_rebalancing](./inventory_rebalancing/) | Transfer inventory between warehouse sites to meet demand at minimum cost. |
| [machine_maintenance](./machine_maintenance/) | Schedule preventive maintenance across time slots to minimize cost while respecting crew-hour capacity and machine conflicts. |
| [network_flow](./network_flow/) | Maximize flow through a capacitated network from a source node. |
| [order_fulfillment](./order_fulfillment/) | Assign customer orders to fulfillment centers to minimize shipping and fixed costs. |
| [portfolio_balancing](./portfolio_balancing/) | Allocate investment across stocks to minimize risk while achieving a target return. |
| [production_planning](./production_planning/) | Schedule production across machines to meet demand while maximizing profit. |
| [retail_markdown](./retail_markdown/) | Set discount levels for products across a selling season to maximize revenue while clearing inventory. |
| [shift_assignment](./shift_assignment/) | Assign workers to shifts based on availability while meeting minimum coverage and per-worker capacity constraints. |
| [supplier_reliability](./supplier_reliability/) | Select suppliers to meet product demand while balancing cost and reliability. |
| [supply_chain_transport](./supply_chain_transport/) | Route shipments from warehouses to customers using multiple transport modes to minimize cost. |
| [test_data_generation](./test_data_generation/) | Determine feasible row counts for test database tables that satisfy schema constraints, then generate example synthetic rows. |
| [traveling_salesman](./traveling_salesman/) | Find the shortest route visiting all cities exactly once and returning to the start. |
| [vehicle_scheduling](./vehicle_scheduling/) | Assign trips to vehicles to minimize total cost, including fixed vehicle activation costs and per-mile costs. |
| [water_allocation](./water_allocation/) | Allocate water from sources to users at minimum cost while meeting demand, subject to connection limits and transmission losses. |
